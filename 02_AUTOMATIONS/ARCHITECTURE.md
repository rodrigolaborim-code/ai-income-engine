# Automations

## A01 — New Lead
Webhook/Form -> Validate -> Save lead -> Tag source -> Send lead magnet -> Start email sequence -> Track event.

## A02 — Lead Qualification
New lead -> Sales/Support Agent -> score intent -> if high intent, send relevant product info -> if support question, route support -> save classification.

## A03 — Purchase
Checkout webhook -> validate event -> save order -> deliver product -> stop sales emails -> start onboarding -> offer upsell after defined delay.

## A04 — Refund
Refund webhook -> save refund -> revoke/adjust access if applicable -> stop upsell -> create support task -> Analytics Agent receives event.

## A05 — Content Factory
Content idea -> Content Agent -> human approval -> save approved content -> schedule manually/through platform -> record URL -> Analytics.

## A06 — Weekly Analytics
Schedule -> pull metrics -> Analytics Agent -> generate report -> save report -> notify owner.

## A07 — Feedback Miner
Feedback form/email -> classify -> Product Agent -> backlog -> weekly review.

## A08 — New Product Opportunity
Research Agent -> score opportunities -> owner approves -> Product Agent creates outline -> launch checklist.
