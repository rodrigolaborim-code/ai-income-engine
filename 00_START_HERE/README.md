# AI Income Engine PT — V2
## AI Business in a Box para produtos digitais

### Objetivo
Construir um sistema semi-autónomo para vender produtos digitais no nicho IA + automação.

### Fluxo principal
Conteúdo -> Lead Magnet -> Captura -> Qualificação -> Email -> Checkout -> Entrega -> Upsell -> Feedback -> Otimização.

### Princípio
Automatiza o que é previsível; usa agentes para tarefas que exigem classificação, pesquisa ou geração; mantém aprovação humana em ações de maior risco.

### Stack
- Orquestração: Make AI Agent (New) ou n8n
- LLM: fornecedor compatível à tua escolha
- Email: plataforma de email marketing
- Checkout: plataforma de produtos digitais
- Base: Airtable/Google Sheets/Notion/Postgres
- Conteúdo: canais sociais à tua escolha

O Make AI Agent (New) suporta instruções, conhecimento, ferramentas e cenários; a própria documentação recomenda agentes para tarefas com entradas/saídas variáveis e julgamento, enquanto fluxos determinísticos devem continuar em cenários normais. citeturn0search0turn0search2

### O que está nesta V2
1. 6 agentes com prompts de sistema.
2. 8 automações com entradas, saídas e regras.
3. Funil de venda completo.
4. Máquina de conteúdo.
5. Biblioteca de produto.
6. Tracking e KPIs.
7. Checklist de implementação.
8. Ficheiro de configuração para ligações/API.
9. Especificações de webhooks.
10. Prompts de QA e segurança.

### Ordem de implementação
Fase 1: checkout + entrega + lead magnet.
Fase 2: email + tracking.
Fase 3: conteúdo + agente de conteúdo.
Fase 4: qualificação + suporte.
Fase 5: feedback + otimização.
Fase 6: upsells e novos produtos.

### Nota
Esta é uma arquitetura pronta para implementação, não uma promessa de rendimento automático. APIs, planos e integrações de terceiros podem mudar; configura as credenciais e os IDs da tua conta antes de ativar os fluxos.
