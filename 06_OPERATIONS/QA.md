# QA de agentes

Antes de ativar:
[ ] prompt tem objetivo claro
[ ] prompt tem limites
[ ] fontes estão definidas
[ ] agente sabe quando dizer "não sei"
[ ] outputs têm formato definido
[ ] existem logs
[ ] existe fallback humano
[ ] não há credenciais no prompt
[ ] dados pessoais minimizados
[ ] existe teste com casos normais
[ ] existe teste com casos adversariais
[ ] existe teste de erro de API
[ ] existe limite de custo/execuções
